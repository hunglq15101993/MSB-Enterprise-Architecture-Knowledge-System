# Deployment Architecture

## Purpose
Describe how the solution is deployed and operated in runtime environments.

## Required Content
- Runtime environment
- Hosting model
- Network topology
- Availability zone strategy
- Storage
- Rollout / rollback

## Review Questions
- Is the deployment model suitable for the workload?
- Are HA and DR considered?
- Is rollback feasible?
- Are storage and network dependencies explicit?

## Evidence
- Deployment diagram
- Network diagram
- Environment layout
- Rollback strategy
