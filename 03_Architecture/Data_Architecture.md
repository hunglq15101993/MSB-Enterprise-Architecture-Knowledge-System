# Data Architecture

## Purpose
Describe how data is structured, stored, shared, and governed across the solution.

## Required Content
- Data entities
- Data ownership
- Source of truth
- Data flow
- Retention

## Review Questions
- Is the authoritative data source clear?
- Are ownership and governance defined?
- Are data dependencies explicit?
- Is retention or archival considered?

## Evidence
- Data model
- Data ownership map
- Data flow diagram
- Retention policy
