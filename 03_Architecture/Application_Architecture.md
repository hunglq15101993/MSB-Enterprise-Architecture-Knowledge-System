# Application Architecture

## Purpose
Describe the major components and how they work together to deliver the solution.

## Required Content
- Components
- Responsibilities
- Dependencies
- Technology stack
- Architecture style

## Review Questions
- Are component responsibilities clear?
- Are dependencies explicit?
- Is the chosen architecture style justified?
- Does the design support business goals?

## Evidence
- Component diagram
- Context diagram
- Integration map
- Architecture rationale
