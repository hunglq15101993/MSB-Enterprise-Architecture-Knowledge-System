# Reference Architecture

## Purpose
Provide a reusable baseline architecture pattern for common solution needs.

- Intended use case
- Standard building blocks
- Assumptions
- Variations
- Constraints

## Review Questions
- Can this solution reuse a standard reference architecture?
- What customizations are required?
- Are deviations justified?

## Evidence
- Reference model
- Standard architecture baseline
- Deviation rationale
