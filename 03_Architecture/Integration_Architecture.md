# Integration Architecture

## Purpose
Describe how systems communicate and exchange data.

## Required Content
- Source
- Destination
- Protocol
- Authentication
- Retry
- Timeout
- Error handling
- Monitoring

## Review Questions
- Is the integration pattern appropriate?
- Are failure handling and retry defined?
- Is the monitoring approach clear?
- Are dependencies explicit?

## Evidence
- Integration matrix
- API catalog
- Sequence diagram
- Error handling design
